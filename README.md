# Teranga Blog

Mini-blog multipage réalisé avec React pour le cours du Professeur Diouf (chapitres 0 à 5).
On peut lire des articles, découvrir leurs auteurs, laisser des commentaires et garder ses articles préférés.
Les données viennent de l'API publique JSONPlaceholder (les textes sont en latin, ce sont des données d'essai).

## Liens

- Dépôt GitHub : https://github.com/Djamilatou-Dolo/teranga-blog
- Adresse en ligne : (à ajouter après le déploiement sur Vercel)

## Fonctionnalités

- Navigation sans rechargement de page (React Router)
- Liste d'articles avec recherche par titre
- Page de détail d'un article avec ses commentaires
- Formulaire de commentaire avec validation
- Favoris : bouton sur chaque article, compteur dans le menu, page dédiée
- Liste des auteurs et fiche de chaque auteur avec ses articles
- Messages de chargement et d'erreur
- Page 404 pour les adresses inconnues
