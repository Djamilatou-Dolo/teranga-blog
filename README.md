# Teranga Blog

Mini-blog multipage réalisé avec React pour le cours du Professeur Diouf (chapitres 0 à 5).
On peut lire des articles, découvrir leurs auteurs, laisser des commentaires et garder ses articles préférés.
Les données viennent de l'API publique JSONPlaceholder (les textes sont en latin, ce sont des données d'essai).
